## 项目名称

**发财小编** — 短视频编导Agent桌面应用

## 核心愿景

用户是短视频编导，想要一个能"蒸馏自己"的系统/Agent——不是简单调 AI API 生成泛泛内容，而是基于数据推演、具备编导专业判断的系统。

## 四个核心维度

输入：一个短视频方向/主题 → 输出整套内容编导方案：

1. **内容策划**：选题、脚本结构、节奏、视觉风格
2. **流量逻辑**：平台算法特性、标题/封面/前3秒钩子、完播率策略、互动引导
3. **变现逻辑**：广告、带货、私域引流等变现路径
4. **数据推演**：基于历史数据/平台趋势来预测和迭代，不是拍脑袋生成

## 关键设计原则

- 不是 AI API 的薄封装，是具备领域知识的专业工作流
- 先不做技术选型，先搞清楚系统到底应该做什么
- 数据驱动优于直觉生成——所以先有了抖音数据提取模块作为数据基础层
- 可能是工作流、Agent 链、或者完整软件——架构待定
