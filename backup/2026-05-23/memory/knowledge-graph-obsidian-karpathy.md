**核心思想：**

- **Obsidian 模式**：知识条目用 Markdown + YAML frontmatter + `[[双向链接]]` 存储
  - 每条知识链接到行业/受众/策略/变现等节点
  - 打开一个节点可看到反向链接的所有项目
  - 检索 = 语义向量入口 → 沿链接展开 1-2 层 → 子图注入 AI

- **Karpathy 理念**：数据质量 > 模型大小
  - 知识条目像训练数据一样精心整理，不是草稿堆
  - 压缩合并 = 像清理训练集一样去重去噪
  - 向量只是检索入口，真正有价值的是链接子图

**对比现状**（纯 JSON + 扁平向量）：

| | 现状 | 目标 |
|---|------|------|
| 存储 | JSON 扁平列表 | Markdown + 双向链接 |
| 检索 | 纯语义相似度 | 语义入口 → 沿图展开 |
| 知识关系 | 隐式（向量里） | 显式（`[[链接]]`） |
| 可读性 | 机器可读 | 人机都可读 |

**Why:** 2026-05-17 讨论变现模式策略时引出，用户提出此方向。
