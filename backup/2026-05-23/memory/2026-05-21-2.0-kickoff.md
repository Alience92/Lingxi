## 决议

1. **API 槽位** — 2.0 实际只需 2 个：general_reasoning（用户可换）+ embedding（系统固定 BGE，对用户隐藏）。搜索独立成搜索源选择。8 槽位是旧代码残留。
2. **Session 替代 Phase** — Session 对话为主入口。Phase 1~10 保留但隐藏，Session 出问题时手动降级。
3. **Phase 配置化** — 2.0 缺失 phaseManifest，路由/DEFAULT_PHASES 倒退为硬编码，缺 PhasePlaceholder。需从 1.0 合并。
4. **反蒸馏** — 基础设施就绪（AES-256 加密 + bundle 校验 + 密钥 IPC），实际 Prompt 加密未实施。2.0 做。
5. **知识库升级** — 待重温讨论（沙漏衰减、语义检索、知识图谱/双链、RAG 注入）。

## 2.0 vs 1.0 关键差异

- Session 对话式入口替代 Phase 0
- 8 大新系统（Session、LAN、沙漏、Embedding、8槽位、反篡改、远程锁、扩展包分发）
- 设计全面重写（手账素描风、浮动侧边栏、自定义 SVG 图标）
- Electron 缺 1.0 安全加固（SQL 白名单、路径沙箱、knowledge_entries 建表）
